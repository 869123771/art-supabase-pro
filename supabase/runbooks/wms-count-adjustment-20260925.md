| 库存调整 | `wms_adjustment_document`、`wms_post_adjustment_secure`、`/wms/transfer-adjustment/adjustment` | 仓位移动、物料、批次、状态、单位、其他批次属性转换；来源扣减、目标新批次入账，生成 `adjustment_out` / `adjustment_in` 双向流水。 |

| 销售发货出库 | SCM `scm_sales_document` 发货通知单、`wms_sales_outbound_allocation`、`wms_post_inventory_movement_secure`、`/wms/receipt-issue/stock-operation` | 已提交通知单按物料行分批出库；每笔关联来源批次、库存流水和 SN。全部明细出库完成后，SCM 通知单自动进入 `shipped`。 |
| MES 完工入库 | MES 报工、确认垛包、`wms_post_inventory_movement_secure`、`/wms/receipt-issue/stock-operation` | 已下达工单先报工，再按未入库量登记生产入库；同一事务生成批次与流水、增加工单累计入库数。已确认垛包按整包块数入库且不可重复办理。 |
| 销售退货入库 | `wms_sales_return_document`、`wms_receive_sales_return_secure`、`/wms/receipt-issue/sales-return` | 关联原销售出库分配，累计退货不得超过该笔出库；保留原项目施工号，原 SN 经退货回库恢复在库，生成退货审计记录及库存流水。 |

批次扩展了生产日期、到期日期、辅助属性、跟踪号、显示单位和显示数量。计量单位转换保持规范库存数量，按 MDM 物料单位换算关系计算目标显示数量。物料转换可以改变目标数量，同时按来源总成本重算目标单位成本。垛包只可整包转换；SN 必须逐件选择，保留两笔流水与同一 SN 的关联记录。调整不能直接改变库存项目归属，跨项目归属必须走项目调拨单。

盘点和调整的业务表对前端只开放受租户范围约束的读取；写入经 `SECURITY DEFINER` RPC、登录身份、租户写入范围与业务按钮权限验证完成。项目施工号关闭时禁止新业务。平台管理员在全部租户视角可基于来源批次确定目标租户；普通用户不能借请求头跨租户操作。

销售出库只能关联已提交的 SCM 发货通知单和其中未出完的物料行。RPC 对租户、物料、项目、施工号、剩余数量、批次可用量和 SN 逐项校验，并在同一事务内写库存流水、出库分配记录与通知单累计出库数量。SCM 的直接“已发货”状态变更以及已有出库后的单据来源字段修改受到数据库触发器拦截。项目发货通知单在提交时必须选择有效施工号；MDM 仓库快捷销售入口跳转至 WMS 出库页，避免调用不带来源单据的旧库存弹窗。出库分配表只开放租户范围内的读取，写入仅由受控 RPC 执行。

MES 旧“交货”仅增加工单数量而不产生库存，现改为跳转 WMS 生产入库；直接调用旧交货 RPC 会收到业务拒绝。生产入库必须带 MES 工单，物料、项目、施工号与工单完全一致，且不得超过已报工未入库量。WMS 工单候选接口支持工单号与 ID 检索，MES 页面跳转可自动定位历史工单。已确认垛包对 WMS 只开放租户范围内的读取，垛包明细提供整包块数；入库锁定垛包、校验块数并阻止重复生产入库。未排包的装配或其他工单仍可按批次入库。MDM 仓库快捷生产入口跳转至 WMS；普通用户只有获得 WMS 查看与入库权限时才会看到相关入口。

WMS 工单领料可按已下达 MES 工单自动带出项目、施工号，也可手动筛选项目施工号与公共库存。来源批次的查询按当前范围过滤；扫码枪回车或手动输入可带入入库批号、逐件录入 SN，出库可按精确批号定位来源库存并逐件选择当前批次 SN。该移动作业入口复用库存作业页面和既有 `WmsStockOperation` 按钮权限。服务端再次校验：关联 MES 工单的出库只能是工单领料，工单必须已下达、未删除；销售出库与直接调拨不能附带工单 ID。正式函数变更前备份于忽略文件 `.artifacts/wms-post-before-issue-guard-20260925.txt`。

直接调拨的目标仓库由来源仓库固定，前端和 RPC 同时拒绝跨仓库一步调拨。每笔直接调拨由 RPC 生成 `DT-日期-随机码` 单号，数据库约束要求单号非空，并以租户及单号唯一索引阻止重复记账。直接调拨列表可按组织、项目、施工号和单号查询；详情展示来源与目标组织、仓库、库位、批次、面积、原因及逐件 SN。数据库函数变更前备份于本地忽略文件 `.artifacts/wms-stock-post-before-direct-transfer-scope-20260925.sql` 和 `.artifacts/wms-stock-post-before-direct-document-20260925.sql`。

垛包读取权限并入 MES 原有的 `tenant_select` 策略，以同一条租户范围谓词授权 MES 排包查看或 WMS 库存作业查看；数据库 advisor 不再报告新增的多条宽松 SELECT 策略。

销售退货按原出库分配单逐笔办理。`wms_sales_return_document` 使用租户范围 RLS，只对已登录账号授予读取；写入仅经 `WmsSalesReturn:Receive` / 原库存入库权限受控 RPC。RPC 锁定原分配，校验累计可退量和退回 SN 是否属于原出库且尚未退过，将原批次项目施工号与板材尺寸、面积比例带到新批次。原 SN 保留编码及父子关系，经合法状态流转重新入库；退货单号在租户内唯一，重试不会重复记账。库存流水以“销售退货入库”展示，仍由原 `other_in` 记账类型参与项目入库统计。新菜单及查看、确认入库按钮各授予既有两类仓储运营角色。
