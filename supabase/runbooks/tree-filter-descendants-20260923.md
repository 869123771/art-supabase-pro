# 树形筛选包含下级（2026-09-23）

目标项目：`ckbftoopuyophiebamwy`。点击左侧树的父节点时，右侧数据查询包含本级及全部下级；点击叶子节点仍只查该节点。页面筛选和导出应使用同一范围。

## 实现

- SMIS 岗位安全责任、岗位风险清单在前端用 `TreeUtils.getDescendants(..., true)` 获取组织 ID；岗位列表、风险岗位、岗位作业指导书的只读函数改为同租户递归组织范围。
- SMIS 题库分类、安全检查组织的只读函数改为递归范围；排查标准页面对排查项传入本级及下级标准 ID。场所、请假、设备、物料、文档、危险废物等已存在递归筛选，未重复改写。
- HR 组织岗位人员关系列表按本级及下级组织查询，岗位行带所属组织 ID；平台管理员选定租户时遵守当前读取范围。
- MDM 运营主档和工艺路线使用本级及下级分组 ID 查询；仓库与生产设备的现有只读函数已经递归筛选，未改写。
- 零部件类别、生产日历、排班日历等左树用于编辑或展示单个节点的页面保留其当前节点语义。

## 数据库交付与回退

只直接替换了六个现有只读函数，未改函数签名、表结构或授权：`smis_list_positions_secure`、`smis_list_risk_positions_secure`、`smis_list_position_work_instructions_secure`、`hr_get_organization_position_directory_secure`、`smis_list_question_bank_secure`、`smis_list_safety_inspections_secure`。

替换前定义保存在本工作区忽略目录 `.artifacts/tree-filter-functions.before.backup.txt`，已核对包含六个函数。回退时先检查当前定义与依赖，在事务中逐个执行对应备份定义并验证权限及返回结果，再提交。此备份不作为迁移文件发布。

## 验证

- 六个函数均先在 `BEGIN` / `ROLLBACK` 中编译验证，再直接替换。实际调用验证：父组织自身 0 个岗位，包含下级后返回 7 个岗位。题库现有数据没有子分类；在回滚事务内临时增加子分类并将现有题目挂到子分类，父分类直接题目数为 0、递归查询为 1，回滚后确认测试分类不存在。安全检查台账当前无记录，函数执行返回 0。
- 平台全部租户、平台选定有效租户、普通用户本租户、普通用户伪造其他租户请求头四种读取上下文已验证；平台选定租户仍返回该租户的 4 个岗位，普通用户伪造请求头后仍读取自身租户。
