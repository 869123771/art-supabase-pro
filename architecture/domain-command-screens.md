# 专业领域大屏

## 范围

本次新增七个只读、租户隔离的领域指挥大屏：AI 安全、安全生产、财务资金风控、流程审批效能、车队安全合规、主数据治理和人力风险效能。页面复用统一的 3D 领域孪生、指标轨、趋势图、分布图、闭环图和优先事项队列；所有指标来自已有业务 API 或新增的 AI 安全事件台账。

## AI 安全事件台账

`public.ai_security_event` 记录不安全结果、越权调用、提示词注入、敏感数据调用、工具失败和模型失败。三个数据库触发器分别监听 `ai_feedback`、`ai_tool_call` 和 `ai_run`，由 `app_private.capture_ai_security_event()` 自动写入事件，业务用户不能直接新增、修改或删除事件。

读取使用 `app_private.tenant_in_current_read_scope(tenant_id)`，因此普通用户只能读取本租户，平台超管仍遵循当前全量或选定租户范围。表启用 RLS，仅授予 `authenticated` 读取权限；平台超管保留受策略约束的维护权限。

应用变更前已经在同一事务内完成建表、索引、RLS、策略和触发器验证并回滚。正式应用后共回填 72 条历史事件，新增 7 个菜单和 56 条角色菜单映射。
